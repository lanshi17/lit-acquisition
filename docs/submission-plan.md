# ECIR 2027 + SIGIR 2027 双线投稿计划

> 2026-08-15 制定。原则:同一工作**不可同时投两个会议**(原创性条款),故为**顺序回退链**:
> ECIR 2027(10/05, CCF-C 保底)→ 被拒则 SIGIR 2027(~01/2027, CCF-A 冲刺)→ 再拒则 CIKM 2027 / JCDL 2027。

## Track 1:ECIR 2027(保底)

### 现状差距
- [ ] **格式转换 ACM → Springer LNCS**(最大工作量,约半天):`\documentclass{llncs}`(Springer 官方模板),包兼容性调整(booktabs/threeparttable/graphics 均可用;`\tick` 的 pifont 需确认),引用仍用 `thebibliography`(LNCS 样式 `\bibliographystyle{splncs04}` 可选)
- [ ] **恢复删减内容到 12 页预算**:ECIR 上限 12 页 > JCDL 的 10 页,把为 JCDL 删掉的**延迟表 + rerank 门控表 + CCS 除外**等加回(约 +0.8 页),保留全文实质
- [ ] 双盲:匿名作者块(LNCS 模板匿名做法 `\author{Anonymous}`),无身份 URL/自引(现有版本已合规)
- [ ] ORCID(Springer 鼓励)
- [ ] EasyChair 账号(ecir27)
- [ ] 摘要 + 标题(09-21,供审稿人 bidding,须与正文一致)

### 风险与应对
- ECIR 是 CCF-C(2026 版降级)——若学校只认 B 以上,此投不满足 → 直接走 Track 2
- LNCS 模板细节(页边距/字体)与 ACM 不同,评审对格式敏感 → 转换后用官方模板对照检查

## 学校政策核查点(先确认再定优先级)

1. 毕业/考核是否要求"CCF 目录内会议"?是 → 主线 ECIR(C)→SIGIR(A)→CIKM(B)
