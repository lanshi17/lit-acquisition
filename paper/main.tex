\begin{abstract}
Variant classification in clinical genetics (e.g., ACMG/AMP guidelines)
requires clinicians to assemble evidence from biomedical literature that is
scattered across many databases, publishers, preprint servers, and languages.
Manual acquisition is slow and leaves coverage gaps, especially for
non-English literature. We present \textbf{lit-acquisition}, an open-source
pipeline that integrates 18+ heterogeneous literature providers --- PubMed,
EuropePMC, Crossref, OpenAlex, Semantic Scholar, preprint servers,
language-specific databases (CiNii, J-STAGE, SciELO), and others --- behind a
single acquisition interface. The system contributes four ideas: (i) a unified
acquisition pipeline with health-aware parallel search and schema
normalization; (ii) LLM-based cross-lingual query translation into six
languages with language-aware provider routing; (iii) citation graph
traversal over Semantic Scholar to discover relevant work beyond keyword
search; and (iv) an LLM relevance gate and open-access-aware download layer
that retrieves full texts only from legal OA sources.

We evaluate the system on a reference gold standard of 30 clinically
relevant genetic variants spanning 541 papers. An ablation study (K=50)
shows that the full pipeline improves Recall@50 from 0.171 (PubMed-only) to
0.348 ($+0.177$, Wilcoxon $p<0.001$), with each component --- multi-source
search, cross-lingual translation, and citation graph traversal ---
contributing additively. Citation graph traversal alone contributes 11
relevant papers that no keyword method finds, concentrated in high-yield
variants such as EGFR and DMPK. Multilingual search recovers non-English
(German, French) relevant literature that English-only search misses. The
toolkit and benchmark are released open-source for reproducible evaluation.
\textbf{Important caveat:} the gold standard annotations were produced by an
automated heuristic protocol and have \emph{not} been verified by domain
experts; we release the dataset as a reference for relative system
comparison, not as clinically certified ground truth (see
Section~\ref{sec:goldstd}).
\end{abstract}

\section{Introduction}
\label{sec:intro}

Interpreting a genetic variant for clinical reporting requires assembling
published evidence: case reports, functional studies, sequencing cohorts,
and guidelines that establish whether a variant is pathogenic or benign.
Under the ACMG/AMP guidelines \cite{richards2015standards}, this evidence
supports criteria such as PS3 (well-established functional effect) and PVS1
(null variant). Evidence is scattered across publisher databases (PubMed,
Crossref, EuropePMC), preprint servers (arXiv \cite{ginsparg1994arxiv},
bioRxiv, medRxiv), regional
and language-specific repositories (CiNii \cite{cinii}, J-STAGE
\cite{jstage}, SciELO \cite{scielo}), and trial and
data registries (ClinicalTrials.gov \cite{zarin2016clinicaltrials},
Zenodo \cite{zenodo}). Clinicians and genetic
counselors routinely search several of these systems manually, deduplicate
results by hand, and risk missing relevant non-English literature.

Commercial tools such as Mastermind \cite{mastermind} and systematic-review
platforms (Covidence \cite{covidence}, Rayyan \cite{ouzzani2016rayyan})
address parts of this workflow, but they are closed-source, cover limited
sources, and do not provide automated open-access full-text retrieval with
explicit license awareness.

We present \textbf{lit-acquisition}, an open-source, MIT-licensed toolkit for
multilingual biomedical literature acquisition. It integrates 18+ providers
behind a uniform interface, adds LLM-based query translation with
language-aware routing, traverses the citation graph for recall, and gates
downloads by relevance and open-access status. This paper makes four
contributions:

\begin{enumerate}
\item \textbf{A unified acquisition pipeline} integrating 18+ heterogeneous
data sources with health-aware parallel search, schema normalization, and
multi-key deduplication (DOI $\rightarrow$ URL $\rightarrow$ normalized title).
\item \textbf{Cross-lingual query translation} using an LLM with a
domain-specific prompt that preserves gene symbols and variant nomenclature,
plus a language-aware provider routing matrix.
\item \textbf{Citation graph traversal} that augments keyword search by
exploring citation and reference edges from seed papers via Semantic Scholar.
\item \textbf{An LLM relevance gate and open-access-aware download layer}
that retrieves full texts only from legal OA sources.
\end{enumerate}

Our ablation study shows that multi-source search, translation, and citation
graph traversal each contribute measurable recall gains, and that the full
pipeline more than doubles PubMed-only Recall@50 on a 30-variant reference
dataset (caveats in Section~\ref{sec:goldstd}).

\section{Related Work}
\label{sec:related}

\textbf{Biomedical literature search.} PubMed \cite{pubmed} and EuropePMC
\cite{europepmc} are the de facto standard sources for biomedical
literature; both expose search APIs with fielded queries. Semantic Scholar
\cite{kinney2023semantic} provides a large-scale citation graph and
paper-level embeddings. These systems are English-centric and each covers a
different subset of the literature, motivating federation.

\textbf{Commercial evidence-acquisition tools.} Mastermind
\cite{mastermind} is a proprietary genomic variant search engine that
aggregates literature per variant; Covidence \cite{covidence} and Rayyan
\cite{ouzzani2016rayyan} support systematic-review screening but are
closed-source and not aimed at full-text acquisition with license handling.

\textbf{Federated / multi-source search.} Meta-search architectures such as
MetaCrawler \cite{selberg1997metacrawler} established result aggregation
from heterogeneous engines; in the scholarly domain, aggregators and
directories such as
OpenAlex \cite{priem2022openalex}, DOAJ \cite{doaj}, BASE \cite{base},
CORE \cite{core}, and OpenAIRE \cite{openaire} expose broad
metadata. Our system treats these as one layer of an acquisition pipeline
rather than a search UI, adding normalization, dedup, and download.

\textbf{Citation analysis in IR.} Bibliographic coupling
\cite{kessler1963bibliographic} and co-citation \cite{small1973co} are
classical similarity measures; PageRank \cite{page1999pagerank} exploits
citation topology for ranking. Literature-based discovery
\cite{swanson1986fish} showed that citation/reference edges carry
unexploited relevance. We use citation edges at acquisition time to widen
recall beyond query matching, similar in spirit to query expansion via
citation neighborhoods.

\textbf{Cross-lingual IR.} Classic CLIR translates queries with bilingual
dictionaries or MT \cite{kishida2005technical}; modern LLMs
\cite{brown2020language,kojima2022large} make translation of short
domain-specific queries practical with minimal setup, which we exploit.

\textbf{Evaluation of IR systems.} Standard practice uses Recall@K,
Precision@K, F1@K, and nDCG@K \cite{jarvelin2002cumulated} with paired
significance tests (Wilcoxon signed-rank \cite{wilcoxon1945individual}).
We follow this protocol on a new, publicly released reference dataset
(Section~\ref{sec:goldstd}).

\section{System Design}
\label{sec:design}

\subsection{Architecture Overview}
\label{sec:architecture}

lit-acquisition is a three-phase pipeline (Figure~\ref{fig:architecture}):
\textbf{(1) Acquisition} fans a query out in parallel across providers with
health-aware prioritization; \textbf{(2) Normalization} unifies the
heterogeneous schemas and deduplicates; \textbf{(3) Relevance Gate \&
Retrieval} ranks candidates, optionally traverses the citation graph, applies
an LLM relevance gate, and downloads open-access full texts.

\subsection{Normalization and Deduplication}

Providers return heterogeneous item schemas. A normalization layer maps each
result into a unified \texttt{OnlineAcquisitionItem} with canonical fields
(title, authors, journal, year, DOI, PMID, language, license, links).
Deduplication merges candidates by DOI, then URL, then normalized title,
in that order of reliability (Table~\ref{tab:dedup}): an incoming item
is dropped if its DOI, URL, or punctuation-stripped lowercase title has
already been seen. Candidates are ranked by title-match strength, DOI
presence, and publication recency before presentation.

\subsection{Cross-lingual Query Translation}
\label{sec:translation}

The \texttt{query\_translator} module uses an LLM with a domain-specific
prompt that instructs the model to translate the query while preserving gene
symbols, variant nomenclature (e.g., \texttt{p.G12D}, \texttt{c.35G>A}),
and disease terminology verbatim. Queries are translated into six languages
(en, zh, ja, de, fr, ru). The language-aware routing matrix
(Table~\ref{tab:routing}) then selects a provider plan per language, e.g.,
Japanese queries additionally target J-STAGE/CiNii, Spanish and
Portuguese target SciELO, and German and French target EuropePMC
(German additionally BASE).

\subsection{Citation Graph Traversal}
\label{sec:citation}

Beyond keyword search, \texttt{citation\_graph.py} performs a BFS over the
Semantic Scholar citation graph starting from seed papers (identified by
DOI). At each hop it collects papers that cite or are cited by the seed, up
to a configurable depth and paper budget. Results are deduplicated against
keyword-search results and merged into the candidate set. This targets a
recall gap: papers that are topically relevant but do not share query
vocabulary with the variant query.

\subsection{Download and Relevance Gate}

Candidates are filtered by an LLM relevance gate that classifies each item
against the user's evidence need (e.g., case reports for PS3) and optionally
filters by literature type (case report, sequencing, functional). Download
routing is license-aware: DOI resolves through Unpaywall
\cite{unpaywall2018} for OA PDFs, PMCID
through EuropePMC, and direct URLs with HTML$\rightarrow$PDF redirect
handling. The system never bypasses paywalls; full texts are fetched only
from OA sources.

\section{Evaluation}
\label{sec:eval}

\subsection{Gold Standard}
\label{sec:goldstd}

We constructed a reference dataset of 30 genetic variants (V001--V030)
spanning cancer genetics (BRCA1, TP53, KRAS, EGFR, BRAF, APC, MLH1, PALB2),
cardiovascular (LDLR, SCN5A, MYBPC3, KCNQ1, FBN1), neurological (MECP2, HTT,
SNCA, APP), metabolic (CFTR, PAH, GBA), hematological (HBB, F8, DMD, G6PD),
and other domains, covering ACMG evidence criteria PS3 (14 variants) and
PVS1 (6 variants) plus 10 additional clinically actionable variants. For
each variant, a clinical geneticist-style query was formulated and candidate
papers were retrieved from multiple sources (PubMed E-utilities, EuropePMC,
Crossref, language-specific databases) and filtered by an automated
heuristic scoring protocol: weighted title/pub-type scoring (gene name in
title: +3; variant identifier: +5; disease keywords: up to +3; preferred
pub-types such as case reports: +2; reviews: $-2$; editorials/letters
excluded). The dataset contains \textbf{541 papers} (mean 18.0 per variant,
range 4--32), with languages including English (289), German (13), French
(11), and 228 records with unknown language metadata. Annotations record
DOI, PMID, title, language, and evidence type.

\textbf{Status and limitations.} This dataset is a \emph{reference set for
relative system comparison}, not a clinically certified gold standard. Its
annotations were produced by the automated protocol above and have
\textbf{not} been verified by domain experts; they may contain both false
positives (papers scoring high on keywords but not actually discussing the
variant) and false negatives (relevant papers the retrieval protocol did
not surface). Consequently, all absolute recall/precision figures in this
paper should be read as indicative of \emph{relative} component
contributions under identical annotation conditions rather than as
clinically accurate coverage estimates. We release the dataset to support
reproducible evaluation; expert re-annotation is future work.

\subsection{Methods Compared}

We evaluate an ablation chain over the same 30 variants, K=50:

\begin{itemize}
\item \textbf{M1: PubMed-only} --- baseline PubMed esearch, English query.
\item \textbf{M2: Multi-source} --- 18 providers, original query, no LLM translation.
\item \textbf{M3: +Translation} --- M2 + LLM query translation (6 languages).
\item \textbf{M4: +Citation graph} --- M3 + citation graph traversal (full pipeline, includes relevance gate).
\end{itemize}

\subsection{Metrics}

For each method and variant we compute Recall@50 (fraction of gold-standard
relevant papers in top-50), Precision@50, F1@50, and nDCG@50
\cite{jarvelin2002cumulated}. Aggregates are reported as mean $\pm$ std over
30 variants; pairwise differences are tested with the paired Wilcoxon
signed-rank test \cite{wilcoxon1945individual}.

\subsection{Main Results}

Table~\ref{tab:main} reports the ablation results. The full pipeline
achieves Recall@50 of 0.348 versus 0.171 for PubMed-only ($+0.177$,
$p<0.001$), and 0.195 nDCG$\rightarrow$0.320 ($+0.125$, $p=0.006$). Each
component contributes additively: multi-source search adds +0.076 recall
($p=0.025$), translation +0.082 ($p=0.037$), and citation graph +0.019
($p=0.21$, not significant at the aggregate level). Figure~\ref{fig:ablation}
shows the underlying per-variant recall distributions: each component
shifts the distribution upward while narrowing cross-variant variance
(std 0.183 for M1 vs.\ 0.099--0.116 for M3/M4).

\textbf{Statistical significance.} Paired Wilcoxon tests on recall confirm
the M1$\rightarrow$M2 ($p=0.025$) and M2$\rightarrow$M3 ($p=0.037$)
improvements. The full pipeline significantly beats PubMed-only on recall
($p<0.001$) and nDCG ($p=0.006$), and beats M2 on recall ($p=0.013$) and
nDCG ($p=0.032$). The M3$\rightarrow$M4 gap is positive but not significant
at the aggregate level ($p=0.21$); however, as Section~\ref{sec:casestudy}
shows, the citation graph contributes relevant unique papers on a subset of
variants. Precision is not significantly different across methods
($p>0.05$), except M3 outperforming M4 on precision ($p=0.004$), consistent
with citation-graph candidates being noisier.

\subsection{Per-variant Analysis}

The aggregate gains concentrate in specific variants. PubMed-only achieves
zero recall on four variants (KRAS p.G12D, BRAF p.V600E, APC, DMD), where
topical keyword queries retrieve none of the gold-standard papers in the
top-50; the full pipeline reaches recall 0.44--0.47 on three of these
(APC recovers only to 0.13). The largest
absolute improvements are V030 DMPK (0.04$\rightarrow$0.56) and V012 EGFR
(0.05$\rightarrow$0.55). Multi-source search improves recall on 20/30
variants (worse on 6), translation improves 17/30 (worse on 11), and
citation graph improves 5/30 (worse on 3, unchanged on 22) --- consistent
with citation traversal acting as a targeted rather than blanket recall
mechanism. Table~\ref{tab:pervariant} lists the largest per-variant gains,
and Figure~\ref{fig:pervariant} shows the full paired comparison: relative
to PubMed-only, the full pipeline improves 20/30 variants, ties 5, and
regresses on 5; the largest regression (MYH7) has a gold set of only 4
papers, where each missed paper costs 0.25 recall.

\subsection{Multilingual Contribution}

Translation and language-aware routing recover relevant non-English
literature (Figure~\ref{fig:multilingual}). In the full pipeline, relevant
papers include German (12) and French (11) records in addition to 50
English records (122 have no language metadata). Notably, PubMed recovers
\emph{zero} relevant papers outside English in this benchmark, while the
multilingual pipeline finds 23 of the 24 gold-standard non-English papers.
This demonstrates that English-only search systematically under-serves
multilingual clinical evidence.

\subsection{Deduplication Effectiveness}

Raw results contain measurable duplication: 8.8\% (M2) and 8.3\% (M3) of
returned records duplicate another record within the same method by DOI
(M4: 6.3\%; M1: 2.8\%); the multi-key deduplication reduces these to unique
candidate sets before ranking. Cross-method overlap is modest: sources are
highly complementary, and no false merges were observed in a manual audit of
50 random pairs. Table~\ref{tab:overlap} shows the pairwise DOI overlap in
the full pipeline --- the four contributing sources are almost completely
disjoint, and the citation graph (200 DOIs) shares zero DOIs with any
keyword source. This confirms that federation and citation traversal are
genuinely additive rather than redundant.

\subsection{Case Study: Citation Graph Recall}
\label{sec:casestudy}

The citation graph contributes most where keyword search is saturated.
Figure~\ref{fig:citation} shows its per-gene contribution. Two variants
stand out:

\textbf{EGFR p.L858R (V012, lung adenocarcinoma).} The full pipeline finds 5
relevant papers \emph{exclusively} via citation graph traversal, including a
2024 JAMA randomized trial (Ivonescimab plus chemotherapy in EGFR-mutated
NSCLC, DOI 10.1001/jama.2024.10613) and a 2023 Lancet Respiratory Medicine
trial (Sintilimab plus chemotherapy). These are recent, high-impact clinical
papers whose titles do not surface under the variant-keyword query used by
M1--M3.

\textbf{DMPK CTG repeat (V030, myotonic dystrophy type 1).} Citation graph
traversal recovers 5 relevant papers missed by keyword search, including a
2019 \emph{Neurobiology of Disease} review of congenital myotonic dystrophy
molecular genetics (10.1016/j.nbd.2019.104533) and a 2022 \emph{Genes}
review (10.3390/genes13020367). These are canonical works connected by
citation edges but not by variant-name lexical match.

\section{Discussion}
\label{sec:discussion}

\textbf{Limitations.} (i) The evaluation dataset is a heuristic-annotated
reference set, not a clinically verified gold standard: its 541 annotations
were produced by an automated scoring protocol (gene/variant/disease
keywords + pub-type weighting) without domain-expert review, so all metrics
are comparative rather than absolute, and absolute recall/precision values
should not be treated as clinical coverage estimates
(Section~\ref{sec:goldstd}); (ii) API rate limits and provider outages
constrained candidate depth (K=50) and citation graph depth; (iii) the
relevance gate depends on LLM quality and cost; (iv) language metadata is
missing for many records (``unknown''), which understates multilingual
analysis precision.

\textbf{Future work.} Embedding-based semantic search over titles/abstracts
to complement lexical and citation-based recall; adaptive citation traversal
depth per variant; automated literature-type-aware gating; and expansion of
the gold standard to 50 variants for greater statistical power.

\section{Conclusion}
\label{sec:conclusion}

We presented lit-acquisition, an open-source multi-source multilingual
biomedical literature acquisition system with citation graph augmentation.
An ablation study on 30 genetic variants (541 papers, heuristic-annotated
reference set) shows the full pipeline doubles PubMed-only Recall@50
(0.171$\rightarrow$0.348), with significant additive contributions from
multi-source search and cross-lingual translation, and complementary recall
from citation graph traversal. The toolkit and dataset are released to
support reproducible evaluation of literature acquisition for clinical
genomics; we stress that the dataset is a reference for relative comparison
and requires expert re-annotation before use as clinical ground truth.
